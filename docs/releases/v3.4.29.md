## T1583.010

High-severity rule that fires when an nftables call adds or
removes a rule in a table family that the operator doesn't
control (e.g. attacker adding to `netdev` while operator
only manages `inet`).

```yaml
selection:
  event_type: nft.call
  table_family_mismatch: true
condition: selection and not filter_table_family_mismatch
timeframe: 5m
count: 1
level: high
```
