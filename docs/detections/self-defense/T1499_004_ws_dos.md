# T1499.004 — WS frame size or rate limit exceeded

**MITRE**: [T1499 — Endpoint Denial of Service](https://attack.mitre.org/techniques/T1499/)
**Sub-technique**: [T1499.004 — Application or System Exploitation](https://attack.mitre.org/techniques/T1499/004/)
**Severity**: High
**Status**: Experimental
**Mapped finding**: [F-009 v3.2.1](../../security/findings/F-009-websocket-no-message-size-cap.md)

## Summary

Detects DoS attempts against `/ws/agent`. Fires when the WS guard
rejects 5 or more frames from the same `src_ip` in a 1-minute window
with `trigger` in `{frame_size_exceeded, rate_limit_exceeded}`. The
threshold is tuned to one full reconnect-and-spam cycle of an abusive
client while still ignoring benign reconnects.

## Detection logic

```yaml
logsource:
  product: zaqorincore
  service: server
detection:
  selection:
    event_type: ws.dos
    trigger:
      - frame_size_exceeded
      - rate_limit_exceeded
  condition: selection
  timeframe: 1m
  count: 5
fields:
  - src_ip
  - agent_id
  - trigger
  - frame_size_bytes
level: high
```

## Sample event

```json
{
  "event_type": "ws.dos",
  "src_ip": "203.0.113.42",
  "agent_id": "agent-prod-02",
  "trigger": "rate_limit_exceeded",
  "frame_size_bytes": 512,
  "ts": "2026-09-03T11:47:09Z"
}
```

## Tuning

- **Whitelist**: `ZAQORIN_SELF_DEFENSE_WHITELIST` (CIDR list).
- **Threshold**: 5 frames in 60 seconds. Raise to 10 for noisy
  environments where benign reconnect storms are common.
- **Known false positives**:
  - Misconfigured agent repeatedly sending oversized heartbeat frames
    (single `src_ip`, easy to whitelist).
