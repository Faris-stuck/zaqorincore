## 15 vuln classes — coverage matrix

| # | Class | Finding(s) | Notes |
|---|---|---|---|
| 1 | API endpoints — auth bypass via alternate paths | CLEAN | All `/api/v1/*` routers checked. `require_role` consistent. No auth path bypass found. |
| 2 | SQL injection | CLEAN | All SQL via SQLAlchemy ORM (`sa_select`, `pg_insert`). One `text("SELECT 1")` in health.py — literal-only, safe. |
| 3 | Path traversal in static / file paths | LOW | `FileResponse(_WEBUI_DIR / "index.html")` uses package-anchored path, no user input. Build-info read uses anchored Path. **No CVE — confirmed safe.** |
| 4 | Deserialization / unsafe loading | CLEAN | No `pickle.load`, no `yaml.load` (only `tomllib.loads` — safe stdlib). |
| 5 | Subprocess / shell injection | CLEAN | No `shell=True`, no `os.system`. nft uses `exec.CommandContext` with structured args (F4 fix). |
| 6 | Timing-attack compares | CLEAN | All secret/sig comparisons use `hmac.compare_digest`. Verified in `auth.py`, `stream.py`, `ingest_cloudflare.py`, `sources.py`, `evidence.py`, `crypto.py`. |
| 7 | Rate limiting / brute force | MEDIUM | `RateLimitMiddleware` covers most routes; ingest endpoints covered. WS not covered (see F-009). |
| 8 | Audit log integrity | MEDIUM | In-memory only (see F-008). No append-only file mode anywhere. |
| 9 | WebUI-specific | MEDIUM | CSP allows CDN React (F-007), `'unsafe-inline'` style (F-016). No `dangerouslySetInnerHTML` found. |
| 10 | Dependency scan | LOW | No known-bad pins (F-014); loose pinning (F-011). `pip-audit` / `govulncheck` not installed in env. |
| 11 | Information disclosure | MEDIUM | `/stats` + `/version` unauth (F-006). `/whoami` leak (F-012). App version drift (F-005). |
| 12 | Cryptographic issues | CLEAN | `secrets` used everywhere. No `random` in security paths. `hashlib.md5`/`sha1` not found for security purposes. |
| 13 | Session/CSRF | N/A | Server is stateless — no operator session cookies. API key auth per-request. CSRF not applicable. |
| 14 | Supply chain | MEDIUM | No lockfile (F-011). All deps use ranges. No LICENSE conflict (all deps MIT-compatible). |
| 15 | WebSocket DoS | MEDIUM | No max-frame-size, no idle timeout (F-009). |

## What was NOT found (good)

* No SQL injection patterns
* No pickle / unsafe-yaml / marshal
* No `shell=True` / `os.system`
* No `hashlib.md5`/`sha1` for security purposes
* No `random.choice` / `random.randint` in crypto paths
* No `==` on tokens/hashes (all use `hmac.compare_digest`)
* No `dangerouslySetInnerHTML` in WebUI
* No `cors` middleware with permissive `allow_origins`
* No hardcoded test creds in production code paths
* No known-bad minimum versions on direct deps

## Top 3 issues (one-line answer)

1. **`/api/v1/stats` + `/api/v1/version` leak version, git SHA, pid, agent count to unauthenticated callers** (F-006)
2. **No lockfile — every dep is a `>=` range, supply-chain drift on every install** (F-011)
3. **`audit` log is in-memory only — lost on process restart, bounded to 1024 entries** (F-008)
